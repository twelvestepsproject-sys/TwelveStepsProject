# מדריך: בלוק "כרטיסיות קישור"

שורת כרטיסיות יפות — כל אחת עם כותרת, טקסט, תמונה וכפתור.

נבנה עבור עמוד ההכשרות כדי להציג את שנה א׳ / ב׳ / ג׳ ולעבור לעמוד הרלוונטי, אבל מתאים לכל מקום שצריך "בחרו אחד מאלה".

| שדה | חובה? |

בנוסף לבלוק: **כותרת אזור** ו**טקסט פתיחה** — שניהם אופציונליים.

## שלב אחר שלב

### שלב 1 — פתיחת העמוד
- **בעמוד רגיל:** `/admin/pages` ← עריכה
- **בעמוד הכשרה:** `/admin/trainings` ← עריכה ← אזור "מבנה העמוד"

### שלב 2 — הוספת הבלוק
בחר **"כרטיסיות קישור"** ולחץ **"הוספת בלוק"**.
הבלוק נוצר עם שלוש כרטיסיות ריקות.

### שלב 3 — כותרת וטקסט פתיחה
לדוגמה:
- כותרת: `שלוש שנות המסלול`
- טקסט: `כל שנה בונה על קודמתה. בחרו שנה לפרטים המלאים.`

### שלב 4 — מילוי הכרטיסיות
לכל כרטיסייה:

1. **כותרת** — למשל `שנה א׳ — יסודות` *(חובה)*
2. **טקסט קצר** — למשל `מוח, מערכת עצבים, התקשרות ומבוא ל־IFS.`
3. **תמונה** — בחר מספריית המדיה או העלה חדשה
4. **כפתור** — שני שדות:
   - טקסט: `לשנה א׳`
   - כתובת: `/shana-aa`

**הוספה:** `+ הוספת כרטיסייה` — ללא הגבלה
**מחיקה:** 🗑 · **סידור:** ↑ ↓

### שלב 5 — שמירה
לחץ **"שמירה"** (או **"שמירת מבנה העמוד"** בעמוד הכשרה).

ללא הגבלה, אבל 3 נראה הכי טוב. מעבר לזה — שורה שנייה.

**חייבים תמונה?**
לא. הכרטיסייה תוצג בלי תמונה, בלי מקום ריק.

**כרטיסייה בלי כותרת?**
