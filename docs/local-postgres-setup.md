# הרצה מקומית עם Postgres

ענף: `migrate-to-self-hosted-postgres`

---

## התחלה מהירה

```bash
npm run setup:local
npm run dev
```

זהו. הפקודה הראשונה מרימה Postgres, יוצרת את הסכימה ומייבאת את כל התוכן
והתמונות. השנייה מריצה את האתר.

**דרישה יחידה:** Docker פועל.

---

## מה `npm run setup:local` עושה

| שלב | פעולה |
|---|---|
| 1 | מוודא ש-`.env.local` מכיל `DATABASE_URL` ו-`DATA_SOURCE` |
| 2 | מרים את Postgres ב-Docker |
| 3 | ממתין שהמסד יהיה מוכן |
| 4 | מריץ את 28 קבצי הסכימה |
| 5 | מייבא 311 שורות תוכן ו-33 תמונות מ-Supabase |

בנוסף נוצר אוטומטית `SESSION_SECRET` ב-`.env.local` — המפתח שחותם על
עוגיית ההתחברות לניהול. הוא נוצר לכל מחשב בנפרד ואסור לשתף אותו.

כל שלב **בטוח להרצה חוזרת** — מה שכבר בוצע פשוט מדולג.

שלב 5 דורש את פרטי Supabase ב-`.env.local`. בלעדיהם הסכימה עדיין נוצרת,
והסקריפט אומר זאת במפורש במקום להיכשל בשקט.

## פקודות

| פקודה | מה היא עושה |
|---|---|
| `npm run setup:local` | הקמה מלאה מאפס |
| `npm run db:up` | הפעלת Postgres |
| `npm run db:down` | עצירה (הנתונים נשמרים) |
| `npm run db:reset` | ⚠️ **מחיקת הכל** ובנייה מחדש של הסכימה |
| `npm run db:migrate` | הרצת מיגרציות חדשות בלבד |
| `npm run db:import` | ייבוא תוכן ותמונות מחדש |
| `npm run db:psql` | פתיחת psql על המסד |
| `npm run db:set-password <email>` | קביעת סיסמה למשתמש ניהול |

## מעבר בין Supabase ל-Postgres

שורה אחת ב-`.env.local`:

```bash
DATA_SOURCE=postgres    # המסד המקומי
DATA_SOURCE=supabase    # הענן
```

צריך להפעיל מחדש את שרת הפיתוח אחרי שינוי.

**שתי המערכות פעילות במקביל** — Supabase לא נגעה, כך שהמעבר הפיך בכל רגע.

## בדיקה שזה באמת עובד

הדרך הבטוחה לוודא שהאתר קורא מ-Postgres ולא מהענן — לעצור את המסד:

```bash
docker stop twelvesteps-postgres
```

עכשיו `/search?q=בדיקה` יחזיר שגיאה 500. אחרי:

```bash
docker start twelvesteps-postgres
```

הוא יעבוד שוב.

**שים לב:** עמודים סטטיים ימשיכו להיטען מהמטמון גם כשהמסד כבוי — לכן
הבדיקה היא דווקא על דף החיפוש, שחייב לגשת למסד בכל בקשה.

## תקלות נפוצות

**"Could not start the database"**
Docker לא רץ. הפעל את Docker Desktop ונסה שוב.

**"postgres did not become ready within 60s"**
```bash
docker compose logs postgres
```
לרוב: פורט 5432 תפוס על ידי Postgres אחר במחשב.

**האתר עולה אבל בלי תוכן**
הייבוא לא רץ. הרץ `npm run db:import`.

**התמונות שבורות**
23 תמונות אכן שבורות — אלה רשומות seed שמצביעות לקבצים שמעולם לא
הועלו. בדקתי מול Supabase: הן מחזירות שגיאה גם שם, כלומר הן היו
שבורות עוד לפני המעבר. שאר התמונות מוגשות מ-`storage/media/`.

**"SESSION_SECRET is missing or shorter than 32 characters"**
הרץ `npm run setup:local` — הוא ייצור אותו. אם הוא נמחק בטעות, כל
המשתמשים המחוברים יצטרכו להתחבר מחדש (זה כל הנזק).

**לא מצליח להתחבר לניהול**
קבע סיסמה מחדש: `npm run db:set-password <email>`. אם הסיסמה נכונה
אבל ההתחברות עדיין נכשלת, ייתכן שהחשבון מסומן כלא-פעיל
(`is_active = false`) — הסקריפט יגיד לך.

## התחברות לממשק הניהול

Supabase לא מייצאת את הסיסמאות המוצפנות שלה, ולכן **אף סיסמה לא עברה
במיגרציה**. צריך לקבוע סיסמה חדשה פעם אחת:

```bash
npm run db:set-password aharon.reiss@gmail.com
```

בלי לציין סיסמה — הסקריפט מגריל אחת חזקה ומדפיס אותה. אפשר גם לקבוע
בעצמך:

```bash
npm run db:set-password aharon.reiss@gmail.com "הסיסמה-שלי"
```

אם המשתמש לא קיים, הסקריפט ישאל אם ליצור אותו כמנהל — כך יוצרים את
המנהל הראשון בשרת חדש.

עכשיו אפשר להיכנס ל-`/admin/login` עם האימייל והסיסמה.

**מה השתנה מתחת:** ההרשאות עצמן לא השתנו — התפקיד עדיין נקרא מטבלת
`profiles` בכל בקשה, כך שהשעיית משתמש או הורדת תפקיד נכנסות לתוקף מייד.
מה שהוחלף זה רק זיהוי המשתמש: במקום JWT של Supabase, עוגייה חתומה
ב-HMAC. אימות דו-שלבי (MFA) לא קיים במסלול הזה — לפי ההחלטה בתכנון.

## מה עדיין לא עובד

| | מצב |
|---|---|
| האתר הציבורי | ✅ עובד במלואו על Postgres |
| התחברות לאדמין | ✅ סיסמאות ועוגייה חתומה, בלי Supabase |
| הגשת תמונות | ✅ מהדיסק (`storage/media/`) |

**אין יותר תלות ב-Supabase בזמן ריצה.** אפשר לוודא: עצור את המסד
(`docker stop twelvesteps-postgres`) — גם ההתחברות לניהול תיכשל, ולא
"תיפול חזרה" לענן.

## הערה על 23 התמונות החסרות

הייבוא מדווח על 23 קבצים שלא נמצאו. אלה רשומות מנתוני ה-seed המקוריים
שמצביעות לנתיב שמעולם לא הועלה — **הן כבר שבורות באתר החי**. שום דבר
לא אבד במעבר.
